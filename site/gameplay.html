首页/功能
FEATURES

把群盘活，也把群管好

接梗、斗图、自己发表情包；关键词、指定会话、免打扰、远程指令。一个搭子，两副面孔。

ALL-IN-ONE

六块能力，装在一个 126 KB 的小程序里

群崽自身零 npm 依赖，把力气都花在「像个真群友」这件事上。

STICKER ENGINE

表情包是会自己长的

群里发来的商城表情与图片，群崽会自动下载本地副本——QQ 图链会过期，本地副本不会。AI 回复里写 [表情] 或 [表情:关键词]，就自动挑一张发出去。

一条回复可以三连，多个表情包打包成同一条消息发出，不会触发刷屏风控。另挂一套在线表情图库（梗鲸 · DeepSeek娘，约 2300 张，每张带台词级描述），群友素材里挑不到时按描述匹配、用到哪张下哪张，只缓存在本机，站点不可达就静默跳过。

  • 面板里可视化增删素材
  • [表情:关键词] 智能匹配
  • 表情批量单条，规避高频风控
MEMORY & VISION

记得住，也看得见

◈

长期记忆

群里说过的事被抽成五类记忆，存 data/memory.json，检索进提示词。

  • 人设 / 近况 / 群梗 / 偏好 / 关系
  • 面板可看可删可手工加
  • QQ 里发 /记忆 关键词 直接查
◎

看图回复

收到图片自动下载后交给大模型看图再回，随时可关。

  • 图片自动落本地
  • 视觉理解后组织回复
  • 开关可控
◷

免打扰与远程指令

设定时段自动闭嘴；主人在 QQ 里就能管。

  • 免打扰时段自动静默
  • /状态 /暂停 /帮助
  • 最小间隔 + 40 秒冷却护栏
