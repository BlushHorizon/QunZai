# 群崽 QunZai v1.4.16

**这一版全是「用起来别扭」的地方：关窗口、找设置、主题发蓝。功能没删也没加，就是把路走顺。**

## 关窗口不再替你做决定

以前点右上角 ×，程序自作主张——要么直接退出把 QQ 桥接一起带走，要么悄悄躲进托盘找不着。现在会弹一个框问清楚：

- **停止服务并退出**：QQ 桥接一起收掉，后台不留东西
- **最小化到托盘**：面板收进托盘，机器人在群里继续说话
- **取消**：什么也不做

托盘菜单里的「退出群崽」也改成「停止服务并退出」，和对话框走同一条路，不会出现「菜单退出了但服务还在跑」。

顺带把「最小化就躲托盘」删了——现在点最小化就是老老实实回任务栏，不再跟你玩捉迷藏。

## 模型设置终于找得到了

这是这一版最该修的东西。以前欢迎页点「模型设置」、模型提供商点「填 Key」，跳过去都是「AI 回复」页的顶部，而真正的参数（网址、Key、模型名、提示词）藏在那页往下 800 像素的地方，看上去就像根本没做设置入口。

现在：

- 网页版引擎、CDP 端口、API 地址、Key、模型名、提示词、测试按钮，整块搬到 **「模型提供商」页**，标题叫「当前大脑的参数」
- 「填 Key」点了直接切到 API 方案 + 把光标放进 Key 输入框 + 全选，可以立刻粘贴
- 这一页补了两个保存按钮（页面右上角、参数面板底部），填完随手就能存
- 欢迎页的「模型设置」「改人设」都指向这里

## 顶栏瘦了，主题黑了

- 顶栏的「停止服务」按钮删了（功能在关窗口的对话框和托盘菜单里，不再摆个按钮误触）
- 「AI 自动回复」总开关从上边挪进 **「AI 回复」页最上方**，勾一下立刻生效，不用再点保存
- 深色主题从深蓝改成中性纯黑，页面底噪那层白色渐变去掉了——以前看着发灰发蓝，现在是纯黑

## 升级说明

覆盖安装保留 `data/` 和 `config.json`，登录态、聊天记录、表情包、人设都不用重做。从 1.4.15 升上来直接装即可。
