# 群崽 QunZai v1.4.13

## 安装器自动关停旧进程

覆盖安装前，安装器会先按安装目录精准结束本程序的所有进程：

- 桌面宿主 `QunZaiHost.exe`
- 主服务 `server\server.js`（node）
- 内置监视器 NapCat / SnowLuma（`engine\...\node.exe`）

只结束落在安装目录内的进程，绝不误杀其他 Node 程序。

**修复的问题**：以前覆盖安装时，内置 NapCat 监视器仍在运行、占用 `engine\napcat` 里的文件，导致报「无法写入 QQNT.dll」而中断安装。
