# 群崽 QunZai

> 让群热闹，也把群管好 —— 住进 QQ 群的 AI 搭子 · 免 API Key · 自己发表情包

群崽通过 **OneBot 11**（SnowLuma / NapCat 等任意实现）接入你的 QQ，用**网页版大模型**当大脑。它干两件事：**把群盘活**（接梗、斗图、自己发表情包）和**把群管好**（@ 才回、关键词、指定会话、免打扰、主人远程指令）。内置网页监控台，连接状态、回复记录、表情包素材全部可视化。Windows 安装包自带 QQ 监视器（NapCat）和它要的 Node 运行时，约 80.6 MB，双击即用。

## 亮点

- **网页版 DeepSeek 直连，免 API Key**：不需要任何 Key，不产生任何 API 账单；用浏览器驱动（CDP）像人一样操作 DeepSeek 网页版。设置里可切换站点档案（新增站点 = 在 `server/web-sites.js` 加一条档案）
- **表情包引擎（核心特性）**：自动收藏所有来信中的商城表情/图片并**下载本地副本**（QQ 图链会过期，本地副本不会）；AI 回复里写 `[表情]` / `[表情:关键词]` 标记就自动发表情包，一条回复可三连，多个表情包**打包成同一条消息**发出，不会触发刷屏风控；面板里可视化增删
- **内置在线表情图库**：另挂一套「[梗鲸 · DeepSeek娘](https://aigengtu.com/DeepSeek%E5%A8%98)」图库（约 2300 张，每张带一句台词级描述）。群友素材里挑不到时，AI 按 `[表情:关键词]` 到这套图里按描述匹配、用到哪张下哪张，只缓存在本机 `data/stickers`；图库只读远端、不镜像整套，站点不可达就静默跳过，不影响聊天
- **只回该回的人**：「指定会话」支持**多选**（Ctrl 点选），选中的会话全部回复，其他一律不回；一个都不选 = 全部回复
- **群聊规矩全套**：需 @ 才回、关键词过滤、非 @ 主动回复概率、自动 @ 触发者、引用原消息、群聊/私聊范围
- **看图回复**：收到图片自动下载后交给 DeepSeek 看图再回（可关）
- **免打扰 + 远程指令**：设定时段自动闭嘴；主人在 QQ 里发 `/状态` `/暂停` `/帮助` 即可管理
- **实时监控台**：网页看板通过 SSE 实时推送消息与回复
- **服务启停内置**：桌面窗口右上角一键停止/启动服务；关闭窗口会停止由它启动的服务，不再需要独立的开启/关闭快捷方式
- **干净**：群崽自身零 npm 依赖（Node ≥ 22 内置能力）、无插件、无商城；Node 运行时随包附带，不用自己装

## 安装与使用

1. 从 [Releases](https://github.com/BlushHorizon/QunZai/releases/latest) 下载最新安装包（当前 v1.4.12，约 80.6 MB，自带监视器与 Node），默认装到 `D:\群崽`，覆盖安装不丢数据
2. 打开设置页 →「监视器（QQ 运行时）」，选「内置的」→ 点「启动并同步」，用手机 QQ 扫面板上弹出的二维码登录一次（小号即可）。不用另外下载 NapCat，也不用装 Node.js
3. 双击桌面「群崽 QunZai」打开监控台 → 点「① 打开该网站」扫码登录一次 DeepSeek 网页版，之后它自己开工；服务启停在窗口右上角

系统要求：Windows 10/11 + 本机已装桌面版 QQ（NTQQ）+ Edge/Chrome + 一台 QQ（建议小号）。
想用自己那份 OneBot 11 运行时（SnowLuma / NapCat / LLOneBot 都行）就在同一处选「我自己找的」填目录。

## 本地开发

```bash
cd app
node server/server.js       # 或 Windows 下双击 start.bat
# 打开 http://127.0.0.1:8787
```

- 无第三方依赖：浏览器控制走 Chrome DevTools Protocol（CDP），WebSocket 用 Node ≥ 22 的全局 `WebSocket`
- 网页站点档案在 `server/web-sites.js`，新增站点 = 加一条档案（选择器、输入框、发送键等都写在里面）
- 内置监视器：把 NapCat 的发行包（full 版，含 `node.exe`）解到 `app/engine-src/napcat/`，`node build-package.js` 会把它同步进 `dist/engine/napcat/` 并由安装包一起装；`--no-engine` 出不含监视器的瘦包。该目录不进 git（体积），许可证全文随包附带（`NOTICE.md` / `LICENSE`）
- 构建安装包：装 [NSIS](https://nsis.sourceforge.io/)，在 `app/` 下执行 `node build-package.js --installer`；脚本会同步 `dist/`、跑隐私闸门并输出安装包

## 官网与 MV

- `site/`：纯静态官网，零外部依赖，双击 `index.html` 即可打开（内嵌 MV 视频与安装包下载）
- `mv/`：这支 MV 没有用任何剪辑软件——配乐是 `make-wav.js` 现场合成的 120 BPM 合成波，画面是 `mv.html` canvas 逐帧离格渲染（`node capture.js 24` 抓帧），`redact.js` 给截图打码。想改歌词/配色直接改 `mv.html` 重跑即可
