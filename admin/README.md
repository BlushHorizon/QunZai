# 群崽官网后台 · 本地控制台

一个跑在你自己电脑上的小软件：改官网文字、换图、维护鸣谢名单，点一下「上传并发布」就推到 GitHub 并自动部署上线。
**不需要装数据库、不需要装依赖、不需要登录任何第三方后台**——官网数据本来就是仓库里的一个 `site/assets/data.js`，这个软件只是把它变成可视化表单。

官网地址：https://blushhorizon.github.io/QunZai/

---

## 一、启动（双击就行）

| 文件 | 用途 |
| --- | --- |
| **start.vbs** | **日常用这个**。双击后无黑窗启动服务并自动打开浏览器控制台。再双击一次只会打开页面，不会重复起服务。 |
| **shortcut.vbs** | 可选：双击在桌面生成「群崽官网后台」快捷方式（指向 start.vbs，带群崽图标）。已经帮你生成好了，桌面直接双击「群崽官网后台」即可。 |
| start.bat | 排错用。带一个黑色命令行窗口，能看到服务日志；**关掉那个窗口 = 停止服务**。 |
| stop.bat | 停止后台服务（start.vbs 启动的是隐藏窗口，看不到，用这个停）。 |

前提：电脑上装了 Node.js（https://nodejs.org ，装 LTS 版一路下一步即可）。没装时 start.vbs 会弹窗提示，不会静默失败。

启动后浏览器打开 **http://127.0.0.1:8899/** 。如果 8899 被占用，服务会自动往后找 8899~8903，实际端口看 start.bat 窗口的输出。

> 软件只监听 127.0.0.1（本机），不对外网开放；关掉服务后任何人都访问不到。

## 二、界面五个页签

- **概览** — 显示官网当前版本号、QQ 群号、各分组条目数、data.js 大小与修改时间；右侧是本地未发布改动清单和最近提交。
- **鸣谢名单** — 重点，见下文。
- **图片素材** — 列出 `site/assets/` 下 45 个文件，带缩略图。点「替换」选本机一张图即可覆盖同名文件（后缀必须一致或在白名单内：png/jpg/jpeg/webp/gif/svg/ico/mp4/exe）。
- **文字内容** — 按分组编辑全站文案：站点信息、链接、事实表、数据卡、标签、功能卡、上手步骤、FAQ、更新日志、图库。改完记得点保存。
- **上传发布** — 看「待发布的改动」、填提交说明（可留空）、点「上传到 GitHub 并发布」，以及查看「运行日志」。

顶栏两个按钮：

- **保存到本地**：只把改动写进本机 `site/assets/data.js`，不会上传。可反复改、反复看预览（左下角「预览官网 ↗」打开的是本机真实页面）。
- **上传并发布**：把 `site/` 下的改动 `git add → commit → push origin main`，触发 GitHub Pages 自动部署。**只有这一步会让线上生效**，一般 1~2 分钟内上线。

快捷键 `Ctrl+S` = 保存到本地；没保存就关页面会拦一下。

## 三、鸣谢名单怎么加（最常用的操作）

1. 左侧点 **鸣谢名单**。
2. 点「添加一位」，填四项：
   - **名字**（必填，如 `小明`）
   - **档位·日期**（选填，如 `¥50 · 2026-11`）
   - **备注**（选填，一句话）
   - **主页链接**（选填，填了名字会变成可点链接）
3. 人多用「批量导入」，一行一位，用 `|` 分隔：
   ```
   小明 | ¥50 · 2026-11 | 谢谢支持 | https://afdian.com/u/xxx
   匿名 | | 加油 |
   ```
4. 点 **保存到本地**，再点左侧「预览官网」看效果。
5. 满意后点 **上传并发布**，填一句提交说明（不填会自动生成），等部署完成即可。

名单为空时官网显示「还没有人上榜 · 这里是第一名的位置 —— 也许就是你的名字。」，不会报错。
改 data.js 前会自动备份到 `admin/.backup/`（保留最近 20 份），写坏了可以手工找回。

## 四、改图片 / 改文字的注意点

- **图片**：官网 HTML 直接引用的 9 张图是 `shot-dashboard.jpg`、`shot-stickers.jpg`、`qq-group-qr.png`、`mv-poster.jpg`、`og-cover.png`、`logo-64.png`、`logo-128.png`、`favicon.ico`、`apple-touch-icon.png`。**替换时保持同名**，否则页面引用不到。
- **版本号**：全站 7 个页面里的桌面版 / 安卓版版本号已接入 `data-config`，在「文字内容 → 站点信息」改 `version` / `apkVersion` 一处，全站同步。
- 官网有缓存串（`?v=...`）和 CDN 边缘缓存，线上看没变先 `Ctrl+F5` 硬刷，或者等 1~2 分钟。
- 「上传并发布」**只提交 `site/` 目录**，绝不会把别处未提交的改动（桌面版 exe、配置等）带上 GitHub。

## 五、发布链路（点一下之后发生了什么）

```
后台保存 → site/assets/data.js（本机）
   ↓ 上传并发布
git add -- site/ → git commit → git push origin main
   ↓ GitHub 收到 push
.github/workflows/pages.yml 自动构建 → GitHub Pages 上线
   ↓
https://blushhorizon.github.io/QunZai/
```

push 用的是本机已有的 git 凭据（gh CLI 登录态），不需要在软件里填任何密码或 token。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击没反应 | 用 start.bat 启动看报错；多半是没装 Node.js。 |
| 页面打不开 | 先运行 stop.bat，再双击 start.vbs；或看是不是端口被占到 8899 之后（start.bat 窗口会写实际端口）。 |
| 点了发布但线上没变 | 发布页看「最近部署」状态；`gh run list --workflow=pages.yml --limit 1`。部署中/失败都会显示。 |
| 线上样式没更新 | `Ctrl+F5` 硬刷。 |
| 改错了想还原 | `admin/.backup/` 里找最近一份 data.js 覆盖回去；或者 `git log` 找上次提交对比。 |
| 想彻底关掉软件 | 运行 stop.bat，然后可以整个删掉 `admin/` 目录（官网不受影响）。 |

## 七、目录说明

```
admin/
├── start.vbs      # 双击启动（无黑窗 + 自动开浏览器）
├── start.bat      # 带窗口启动（排错用）
├── stop.bat       # 停止后台服务
├── server.js      # 本地服务：零依赖，Node 内建模块
├── ui/            # 控制台网页（index.html / app.js / app.css）
├── .backup/       # 自动备份（不进 Git）
└── README.md      # 本文件
```

它不改动官网的任何架构：官网仍然是纯静态 8 个 HTML + data.js + site.js + style.css，后台只是本地的编辑器与发布器。

> 提示：「主页链接 / 联系方式」一栏只有以 `http://` 或 `https://` 开头才会变成可点击链接；填 QQ 号、微信号等纯文本会作为联系方式显示在卡片里，不会生成坏链接。

> 安全说明：点「上传并发布」只会提交内容与素材的**新增/修改**，不会把工作区里手动删除的 `site/` 文件一起发布——后台没有删除素材的功能，这样能避免误删仍被引用的图片导致官网破图。若确实要删某张图，请告诉我单独处理。
